# 🧠 OmniBrain — Your Second Digital Brain

OmniBrain is an autonomous memory agent designed to capture, organize, and synthesize knowledge across multiple formats (Text, PDFs, YouTube Videos, and Websites). Built for the "Rise of the Agents" hackathon.

## 🚀 Features
- **Multimodal Ingestion:** Ingest text notes, PDFs, YouTube transcripts (with exact timestamp matching), and scraped website data.
- **Agentic Planner & Summarizer:** Generates date-wise action plans and structured briefs.
- **Autonomous Deadline Scanner:** Scans unstructured memories for hidden exams/deadlines.
- **Non-Consensual Action Safeguard:** Features a strict human-in-the-loop "Approve/Reject" gate before executing plans.
